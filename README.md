# PIER360

Plataforma Unificada de Segurança com interface de gestão de ativos e vulnerabilidades, acesso multi-tenant e integração planejada com Wazuh.

## Aplicações

- `apps/platform`: aplicação Next.js para autenticação e administração.
- `apps/web`: protótipo interativo PIER360.
- `supabase/migrations`: histórico versionado do banco.

## Configuração local

Veja `apps/platform/.env.example` para as variáveis esperadas. Não envie segredos ao repositório.
